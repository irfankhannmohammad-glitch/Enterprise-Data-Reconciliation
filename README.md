# Enterprise Data Reconciliation & BI Dashboard

## Project Overview

This project focuses on analyzing and reconciling enterprise transaction data using Python, data processing techniques, and Microsoft Power BI.

The project transforms raw transaction and exchange-rate data into a cleaned and analysis-ready dataset and presents key business insights through an interactive Power BI dashboard.

## Objectives

- Analyze enterprise transaction data
- Clean and reconcile transaction records
- Convert financial values into USD
- Identify failed and successful transactions
- Analyze revenue trends over time
- Identify the top customers by revenue
- Build an interactive Power BI dashboard
- Provide business insights through visual analytics

## Tools & Technologies

- Python
- Pandas
- Microsoft Power BI
- Microsoft Excel / CSV
- Data Cleaning
- Data Analysis
- Data Visualization

## Dataset

The project uses transaction, reconciliation, and exchange-rate related datasets.

The main analysis-ready dataset is:

`power_bi_ready_dataset.csv`

Additional processed datasets include:

- `reconciled_final.csv`
- `transactions_final.csv`

## Power BI Dashboard

The Power BI dashboard provides:

- Total USD Revenue
- Total Transactions
- Failed Transactions
- Revenue Trend Over Time
- Top 5 Customers by Revenue
- Date-based filtering

The dashboard allows users to interactively explore the transaction data and understand important financial and operational trends.
